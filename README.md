# Cửa cuốn

Trang bấm cửa cuốn từ xa qua broker MQTT.

Trang này **không chứa mật khẩu**. Nó hỏi tài khoản MQTT một lần rồi giữ trong máy bạn
(localStorage). Không có tài khoản thì mở trang ra cũng không bấm được gì.

Sinh ra từ `page.html` bằng `build_cloud.py` nằm trong repo firmware (repo riêng).
